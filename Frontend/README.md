# RentEase – Full Student Rental Web Application

This is a frontend MVP built directly from the RentEase project requirements.

## Requirements covered
- Responsive web platform
- User registration/login demo
- Furniture and appliance catalog
- Product details
- Monthly rent + security deposit
- 1/3/6/12 month tenure
- Cart and checkout
- Delivery date and address
- Active rental management
- Maintenance/support request
- Rental history stored in browser localStorage
- Admin/vendor dashboard demo
- Inventory view
- Active rentals, MRR and support KPIs
- Mobile-first responsive UI

## Run
Open `index.html` in Chrome/Edge. No installation is required.

## Important
This is a frontend prototype. Login, booking and support data are stored only in browser localStorage. There is no real payment gateway or server database.
